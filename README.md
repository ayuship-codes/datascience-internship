# Data Science with Python Internship

## About the Internship

This repository contains the assignments, practical exercises, and projects completed during my **Data Science with Python Internship at SkillNexis**.

The internship focuses on developing practical skills in Python programming, data analysis, data cleaning, visualization, and basic machine learning concepts.

The work is organized week-wise to keep the assignments and learning progress structured.

## Technologies & Tools Used

- **Programming Language:** Python
- **Libraries:** NumPy, Pandas, Matplotlib, Seaborn
- **Database:** MySQL
- **Development Environment:** Jupyter Notebook, VS Code
- **Version Control:** Git and GitHub
- **Data Visualization:** Python visualization libraries
- **Machine Learning:** Regression concepts and model evaluation

## Weekly Assignments

### Week 1 – Python Fundamentals and Introduction to Data Analysis

**Topics Covered:**
- Python fundamentals and basic programming concepts
- Variables, data types and data structures
- Conditional statements and loops
- Functions and basic scripting
- Introduction to NumPy and Pandas
- Understanding datasets and basic data operations

**Learning Outcome:**

Developed a foundation in Python programming and learned how Python libraries are used for working with data.

### Week 2 – Python Data Analysis Using Pandas

**Topics Covered:**
- Loading CSV files using Pandas
- Exploring datasets using `head()`, `info()` and `describe()`
- Handling missing values
- Identifying and removing duplicate records
- Grouping data using `groupby()`
- Sorting data using multiple columns
- Creating correlation matrices

**Practical Tasks:**
- Analysed a sales dataset.
- Calculated total revenue for different categories.
- Cleaned missing and duplicate records.
- Sorted sales data and explored relationships between numerical columns.

**Tools Used:** Python, Pandas, Jupyter Notebook.

### Week 3 – Data Cleaning and Data Visualization

**Topics Covered:**
- Data inspection and preprocessing
- Handling missing values using median
- Removing duplicate records
- Filtering rows and creating new columns
- Exploratory Data Analysis (EDA)
- Data visualization using Matplotlib and Seaborn

**Practical Tasks:**
- Analysed a student performance dataset.
- Cleaned and processed the dataset.
- Created additional columns such as Result, Attendance Status and Study Category.
- Generated visualizations to understand student performance.
- Exported the cleaned dataset into a CSV file.
- Identified important observations from the analysis.

**Tools Used:** Python, Pandas, Matplotlib, Seaborn, Jupyter Notebook.

### Week 4 – Sales Analysis and Predictive Modeling

**Topics Covered:**
- Exploratory Data Analysis on sales data
- Data cleaning and preprocessing
- Identifying sales trends and patterns
- Regression-based sales prediction
- Understanding model evaluation metrics
- Data visualization and dashboard development
- Generating business insights and recommendations

**Practical Tasks:**
- Explored and analysed a sales dataset.
- Identified trends across categories, regions and time periods.
- Worked on the concept of regression for sales prediction.
- Explored model evaluation metrics such as MAE, MSE and R².
- Prepared visualizations and summarized findings.
- Worked on presenting data-driven business insights.

**Tools & Technologies:** Python, Pandas, Matplotlib, Seaborn, Excel and introductory machine learning concepts.
